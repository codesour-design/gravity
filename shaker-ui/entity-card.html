Entity Card

Parametric card for displaying Gravity domain entities — installations, campaigns, connected systems. Composed of a header (title + badges), optional image, structured body fields, and an optional footer action bar.

When To Use

Use Entity Card to display a compact, scannable summary of a domain object in grids or lists where multiple entities need to be compared at a glance.

  • Header — title, one or more colour-coded badges, optional kebab menu
  • Image — optional slot with configurable aspect ratio or fixed height
  • Body — icon + label + value fields in 1 or 2 columns
  • Footer — optional action bar: any React node

Anatomy

The card stacks four vertical slots. Only title is required — every other slot is omitted from the DOM when its prop is not provided.

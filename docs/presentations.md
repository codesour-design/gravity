# Template presentazioni — Gravity

> **Regola:** ogni presentazione (Google Slides, deck, pitch, documento a slide) parte SEMPRE dal
> template ufficiale fatto a mano da Gloria — mai da zero, mai reinventare cover/colori/font.

- **File master (Google Slides):** `Gravity_Template`
  - URL: https://docs.google.com/presentation/d/1wcofnhmrZw9VWBZ1T5cZkRexA8x2Z_wqTS7cmqrf_2k/edit
  - Drive file ID: `1wcofnhmrZw9VWBZ1T5cZkRexA8x2Z_wqTS7cmqrf_2k`
- **Per una nuova presentazione:** **duplicare il file master** (copy_file) e riempire le slide,
  oppure applicarne i layout. Mantenere cover, colori (`#3E00FB` / `#FF4A1C`), font
  (Oswald/Inter — che qui, a differenza dell'interfaccia, sono corretti: sono i font del brand)
  e stile.
- **Layout disponibili (8):** Cover · Indice · Divisore di Sezione · Contenuto
  (titolo+testo+bullet) · Due colonne · Card "3 pilastri" · Statistiche/numeri · Chiusura.

> Nota storica: la cartella `presentation-template/` (generatore PPTX in Python + template
> PowerPoint) è stata rimossa dal repo il 2026-07-02 — la fonte di verità è il file Google
> Slides qui sopra. Se servisse di nuovo un `.pptx`, gli script sono recuperabili dalla history git.
